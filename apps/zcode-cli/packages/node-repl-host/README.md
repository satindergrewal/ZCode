# @zcode/node-repl-host

Shared host for `node_repl`: the JS execution surface (a single `js` tool) and the two
domain bridges (Browser Use, Computer Use) live here.

## Why it is a separate package

The host is **shared by the official capabilities** and belongs to no single plugin. It used to
live in `browser-use-plugin`, which caused:

- changing Computer Use meant touching the browser-use package;
- the CUA SDK and docs each had a hand-maintained copy inside browser-use;
- `resolveBuiltInNodeReplMcpServers` looked for the host artifacts only under browser-use's
  rootPath, so once the browser-use package was missing, the host was unreachable even when
  CUA itself was enabled.

Registration was already centralized in the CLI core (`bootstrap/src/app/built-in-node-repl.ts`,
triggered when either `bua` or `cua` is enabled); what was always missing was **artifact
ownership**. This package moves the source to where it belongs.

## Artifacts are still carried by the plugin packages

`dist/mcp/server.js` and `scripts/computer-use-client.mjs` are listed in the SEA release
manifest (`OFFICIAL_BROWSER_USE_REQUIRED_SEED_PATHS`) and their paths must not change. So
browser-use's build bundles this package's `src/server.ts`, and the CUA client/docs copies are
generated by the build script instead of maintained by hand. Moving the artifacts out of the
plugin roots as well would require changing both the SEA manifest and bootstrap's hostPackage
resolution, and is a separate step.
